# ProTyping — тренажёр слепой печати

Минималистичный онлайн-тренажёр слепой печати: последовательные уроки для новичков,
свободная практика для опытных, виртуальная клавиатура с подсветкой клавиш и зонами
пальцев, статистика с графиками. Поддерживаются раскладки **ЙЦУКЕН** (русская) и **QWERTY** (английская).

Без регистрации: все данные хранятся в браузере (localStorage).

## Как запустить

Ничего устанавливать не нужно.

1. Откройте папку проекта в VS Code.
2. Дважды щёлкните `index.html` (откроется в браузере).
   Удобнее — расширение **Live Server** в VS Code: правый клик по `index.html` → *Open with Live Server*.
   Тогда страница сама обновляется после каждого сохранения файла.

## Как выложить в интернет (GitHub Pages)

1. На GitHub откройте репозиторий → **Settings** → **Pages**.
2. В *Source* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите *Save*.
3. Через минуту сайт будет доступен по адресу вида `https://<ваш-логин>.github.io/blind-typing-simulator/`.

## Устройство проекта

```
index.html          — единственная HTML-страница: все разделы сайта (<section class="view">)
css/style.css       — всё оформление, светлая и тёмная темы (CSS-переменные)
js/i18n.js          — переводы интерфейса (русский / английский)
js/storage.js       — сохранение настроек, истории и прогресса в localStorage, экспорт/импорт
js/layouts.js       — раскладки клавиатуры и то, каким пальцем нажимается каждая клавиша
js/texts.js         — слова, предложения и тексты для тренировок
js/exercises.js     — генерация упражнений свободной практики и уровни сложности
js/lessons.js       — уроки режима обучения
js/keyboard.js      — виртуальная клавиатура (отрисовка, подсветка, вспышки)
js/hands.js         — полупрозрачные руки поверх клавиатуры (SVG): нужный палец тянется к клавише
js/trainer.js       — «движок» тренировки: ввод, ошибки, WPM, точность, результаты
js/stats.js         — страница статистики (карточки, график, история)
js/app.js           — навигация между разделами и логика страниц
js/vendor/          — библиотека графиков Chart.js 4.4.1 (лицензия MIT)
```

Скрипты подключаются обычными тегами `<script>` в конце `index.html`, порядок важен:
каждый следующий файл пользуется функциями предыдущих.

## Правила подсчёта

- **WPM** = (верно набранные символы / 5) / минуты. «Слово» = 5 символов — общепринятый стандарт.
- **Точность** = (все нажатия − ошибочные) / все нажатия × 100%.
- После ошибки курсор идёт дальше, Backspace разрешён, но ошибка остаётся в счётчике, даже если её исправить.
- Урок засчитывается при точности от 90%, после этого открывается следующий.

## Как добавить новый язык

1. В `js/layouts.js` добавьте раскладку в `LAYOUTS` (символы для каждого ряда клавиш).
2. В `js/texts.js` добавьте слова, предложения и тексты.
3. В `js/lessons.js` добавьте порядок изучения клавиш в `LESSON_PLAN`.
4. В `js/i18n.js` добавьте название языка (`'lang.xx'`).
